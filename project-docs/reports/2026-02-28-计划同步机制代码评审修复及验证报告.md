## 2. 缺陷修复验收细节

### ✅ 致命缺陷：绝对路径死链破坏协同环境

- **验收情况：已修复**。
- **验证手段**：查看 `src/hooks/start-work/sync-plan.ts`，原先强制的 `resolve(planPath)` 已经被撤除。如今统一采用 `path.relative(dirname(targetPath), planPath)` 函数处理。
- **架构收益**：生成的所有 `project-docs/plans/*.md` 链接现已变为纯对内相对定位（例如：`../../.sisyphus/plans/xxx.md`）。在多台开发者电脑、跨磁盘间同步时，这确保了 Symlink 无论怎样都不会呈现为 Broken Link。

### ✅ 关键缺陷：死链下触发防卫重置丢失引起的 EEXIST 崩溃

- **验收情况：已修复**。
- **验证手段**：删除了脆弱且在死链时行为异常的 `if (existsSync(targetPath))` 保护壳代码，取而代之的是纯粹且具备幂等保障的覆盖擦除 `rmSync(targetPath, { force: true })`。
- **架构收益**：彻底绝杀 EEXIST （File Already Exists）的幽灵错误可能，保障了 Hook 流转时的健壮生命周期吞吐率。Node 文件系统的底层容错率被发挥到了极致。

### ✅ 附加优化：测试金字塔与 Mocking (TDD)

- **验收情况：测试重构完成且全面覆盖**。
- **验证手段**：由于原先的实际物理写入测试在各种类 Unix 系统或 MacOS 上极易出现 Temp 文件夹的权限隔离错误（`EPERM`），测试包 `sync-plan.test.ts` 被深度重构，通过彻底的在纯内存级别接管拦截并注入（`spyOn(fs)`）以保障无外设依赖。目前 4 个核心断言已 100% 全绿通过（包含验证相对路径参数的一致性校验）。
