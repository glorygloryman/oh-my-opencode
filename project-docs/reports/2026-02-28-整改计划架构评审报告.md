**这是完全相反的操作！** 整改计划误解了评审报告的问题描述，将"使用绝对路径导致问题"错误理解为"应该使用绝对路径来解决问题"。

评审报告标记为 **⚠️ Important** 的第二个缺陷在整改计划中**完全未被提及**：

**评审报告原文（第 38-56 行）**：

问题：当 `targetPath` 是死链接时，`existsSync` 返回 `false`，`rmSync` 被跳过，导致后续 `symlinkSync` 抛出 `EEXIST` 异常。

```typescript

```

**整改计划**：❌ **完全未提及此问题**

## 四、技术原理验证

### 4.1 Git 软链接最佳实践

```bash
# 绝对路径软链接 - ❌ 不可移植
lrwxr-xr-x  link -> /Users/cy/project/.sisyphus/plans/plan.md
# 协作者克隆后：死链（路径不存在）

# 相对路径软链接 - ✅ 可移植
lrwxr-xr-x  link -> ../../.sisyphus/plans/plan.md
# 协作者克隆后：有效（相对路径正确解析）
```

### 4.2 路径场景矩阵

| 场景 | 源文件路径 | 目标路径 | 相对软链接 | 绝对软链接 |
|------|-----------|---------|-----------|-----------|
| 开发者 A 本地 | `/Users/A/proj/.sisyphus/plans/p.md` | `/Users/A/proj/project-docs/plans/p.md` | `../../.sisyphus/plans/p.md` ✅ | `/Users/A/proj/.sisyphus/plans/p.md` ❌ |
| 开发者 B 克隆后 | `/Users/B/proj/.sisyphus/plans/p.md` | `/Users/B/proj/project-docs/plans/p.md` | `../../.sisyphus/plans/p.md` ✅ | `/Users/A/proj/...` 死链 ❌ |

**结论**：只有相对路径软链接才能保证跨环境可移植性。整改计划的绝对路径方案**完全错误**。

## 六、正确修复方案参考

### 6.1 源码修复 (`sync-plan.ts`)

```typescript
// sync-plan.ts 正确修复
import { existsSync, mkdirSync, statSync, symlinkSync, rmSync } from "node:fs"  // 移除 lstatSync
import { join, relative, dirname } from "node:path"  // 新增 relative, dirname

export function syncPlanToProjectDocs(ctx: PluginInput, planPath: string): SyncPlanResult {
  try {
    if (!existsSync(planPath)) {
      return { success: false, error: `source plan ${planPath} does not exist` }
    }

    const stat = statSync(planPath)
    const date = new Date(stat.birthtimeMs || stat.mtimeMs)
    const dateStr = date.toISOString().split("T")[0]

    const rawPlanName = getPlanName(planPath)
    const cleanPlanName = rawPlanName.replace(/\.md$/, "")

    const targetDir = join(ctx.directory, "project-docs", "plans")
    if (!existsSync(targetDir)) {
      mkdirSync(targetDir, { recursive: true })
    }

    const targetPath = join(targetDir, `${dateStr}-${cleanPlanName}.md`)

    // 关键修复 #1: 无条件删除（解决死链问题）
    rmSync(targetPath, { force: true })

    // 关键修复 #2: 使用相对路径（解决跨环境问题）
    const relativePlanPath = relative(dirname(targetPath), planPath)
    symlinkSync(relativePlanPath, targetPath)

    return { success: true, targetPath }
  } catch (e) {
    const err = e instanceof Error ? e.message : String(e)
    return { success: false, error: err }
  }
}
```
